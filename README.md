# PasteMate

> Windows 桌面悬浮「粘贴助手」工具条 —— 按一次热键，把剪贴板里的乱码文本变成能直接用的格式。

很多时候你复制到的东西是「机器格式」：压缩成一行的 JSON、一长串 Base64、URL 编码后的中文字符串、或者一个十位数的时间戳。
你需要的是能读、能贴进文档/聊天框的样子，但手边没有顺手的转换工具。

PasteMate 常驻系统托盘，按 `Ctrl + Shift + F` 在鼠标旁弹出一个小工具条：
把内容粘进去，下方实时显示转换结果，按 `Enter` 或点 📋 直接写回剪贴板。用完自动关闭，不占地方。

## 功能

### 智能识别（按优先级依次尝试）

| 优先级 | 规则 | 示例 |
| --- | --- | --- |
| 1 | **JSON 格式化** | `{"a":1,"b":[2,3]}` → 缩进 2 空格、保留中文 |
| 2 | **时间戳转换** | `1700000000` / `1700000000000` → `2023-11-15 06:13:20` |
| 3 | **URL 编码解码** | `%E4%B8%AD%E6%96%87` → `中文` |
| 4 | **Base64 解码** | `aGVsbG8gd29ybGQ=` → `hello world` |
| 5 | **纯文本清理** | 统一换行符、压缩多余空行与连续空格 |

任何一条规则失败就落到下一条，**永远不会报错退出**，最差情况原样返回。

### 界面

```
┌──────────────── 输入框（占满） ─────────────────┬─ 📋 ─┐
│ 粘贴 / 输入原始文本                              │ 复制 │
├─────────────────────────────────────────────────┴──────┤
│ 预览面板：实时结果（多行、可滚动、高度自适应）            │
├────────────────────────────────────────────────────────┤
│ ✅ 小字提示命中的规则（如 "检测为 JSON"）                 │
└────────────────────────────────────────────────────────┘
```

* 预览面板随内容长高（最多 8 行，超出可滚轮查看），空输入时收回最小高度；
* 超长内容预览只渲染前 20,000 字符并明确提示，**复制始终是完整结果**；
* 失去焦点（点击别处）自动关闭；`Esc` 关闭但不复制。

### 其它

* **单实例**：重复启动只会唤醒已有实例，不会开出第二个托盘图标；
* **开机自启**：托盘右键菜单一键开关（写 `HKCU` 注册表，无需管理员权限）；
* **前台抢占**：用「ALT 技巧 + AttachThreadInput + 重试」确保弹窗出来就能直接打字；
* **高 DPI 感知**：高分屏下字体清晰、坐标正确。

## 安装

需要 **Python 3.8+**（Windows）。`tkinter` 是标准库自带。

```bash
pip install -r requirements.txt
python pastemate.py
```

或者直接**双击 `启动.bat`** —— 它会自动检查并安装缺失的依赖，然后用 `pythonw` 在后台启动（不弹黑色控制台窗口）。

启动后没有主窗口，只在系统托盘出现一个蓝色剪贴板图标。按 `Ctrl + Shift + F` 呼出工具条。

### 依赖

* [pynput](https://pypi.org/project/pynput/) — 全局热键（低级键盘钩子，普通权限即可）
* [pyperclip](https://pypi.org/project/pyperclip/) — 剪贴板读写
* [pystray](https://pypi.org/project/pystray/) — 系统托盘图标
* [Pillow](https://pypi.org/project/Pillow/) — 程序内绘制托盘图标（不需要外部 .ico 文件）

## 自定义

| 想改什么 | 怎么改 |
| --- | --- |
| **热键** | 修改源码里的 `HOTKEY`（pynput 语法）：`'<ctrl>+<alt>+v'`、`'<ctrl>+<shift>+<f5>'` 都行 |
| **单实例端口** | 环境变量 `PASTEMATE_PORT`，或改 `SINGLETON_PORT` 常量 |
| **保留原始空格** | 纯文本清理默认会把连续空格压成一个（会动到代码对齐）；注释掉 `process_text()` 规则 5 里的那行 `re.sub` 即可 |
| **调试日志** | 设 `PASTEMATE_DEBUG=1` 在前台运行，能看到热键/抢焦点/端口选择的诊断输出 |

> ⚠️ **热键会被系统独占**：PasteMate 用 `RegisterHotKey` 注册了 `Ctrl+Shift+F` 作为备用通道，因此运行期间**其它程序收不到这个组合键**。如果它和你的 IDE / 编辑器冲突，请按上表换一个键。

## 已知限制

* **仅支持 Windows**：大量使用 `ctypes.windll`、注册表、`RegisterHotKey`、DPI API。
* **复制的是纯文本**：不保留 HTML / RTF / 图片等剪贴板格式。
* **长数字会被当时间戳**：10 位或 13 位纯数字若落在 1970–2100 年范围内，会被转成日期。若你经常处理这类订单号/ID，可以调整或关掉规则 2。
* **预览有渲染上限**：前 20,000 字符（复制不受影响）。

## 实现备注

几个踩过坑、值得记下来的点：

* **输入框和预览框都必须用 `tk.Text`，不能用 `tk.Entry`。**
  `tk.Entry` 处理超长字符串是 O(n²) 的：实测插入 8,000 字符要 1.2 秒、16,000 字符要 4.9 秒，而同样的操作 `tk.Text` 只要 0.0 ms。粘贴一大段 JSON 时 Entry 会把 tkinter 主线程卡死几十秒，Windows 判定"未响应"，看起来就像程序崩溃。
* **不要用 `Text.count(..., 'displaylines')` 算行数。**
  它同样是超线性的（单行 8,000 字符要 9.7 秒）。这里改用字体度量 `font.measure` 估算，并且凑够 8 行就立即返回。
* **Base64 识别需要防误判门槛。**
  `file` / `edit` / `byte` / `bits` 这类普通英文单词恰好符合 Base64 字符集与长度，解码后得到 `~)^` 这样的可打印短串，会把原文悄悄改掉。因此要求**解码结果至少 4 个字符**——这个阈值是用语料（近 700 个真实词/标识符 + 12,000 个随机串，24 个真样本）量出来的，做到真实词 0 误判、真样本 0 漏检。
* **双热键通道**：`pynput` 钩子为主，Win32 `RegisterHotKey` 为备——即使安全软件拦截了钩子，热键依然有效。
